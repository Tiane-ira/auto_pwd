自动填充插件测试页面

使用说明：

1. 在浏览器扩展页面启用本插件

2. 点击插件图标打开管理面板，为输入框添加 XPath 选择器规则（如 //input[@id='username']、//input[@name='password'] 等）

3. 多数据组功能：在规则中可添加多组数据（如「默认分组: admin」、「测试账号: test_user」），并可设置某组为默认

4. Chrome 密码管理交互：

    • 页面刷新时会自动使用默认数据组填充表单

    • 鼠标 hover 到表单输入框最右侧，会出现 🔑 钥匙图标

    • 点击 🔑 钥匙图标可选择任一数据组一键切换整套表单填充值

XPath 选择器示例

  • //input[@id='username'] - 通过 ID 属性定位
  • //input[@name='email'] - 通过 name 属性定位
  • //input[@name='password'] - 通过密码框属性定位
  • //input[@id='fullname'] - 通过 ID 定位输入框
  • //form[@id='testForm1']//input[1] - 相对路径定位表单内输入框
  • //select[@id='country'] - 定位下拉框
